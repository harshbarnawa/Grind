# C++ OOP Concepts Demonstration

A complete C++ program demonstrating almost all major Object-Oriented Programming (OOP) concepts in a single file.

This project is made for:
- Learning OOP in C++
- Revision before interviews/viva
- Understanding inheritance and polymorphism
- Practicing advanced class concepts

# Features Demonstrated

## Encapsulation
Private data members with controlled access using getters/setters.

## Abstraction
Implemented using abstract class and pure virtual functions.

## Polymorphism
Runtime polymorphism using virtual functions and base class pointers.

## Operator Overloading
Custom `+` operator for combining vehicles.

## Function Overloading
Multiple functions with same name but different parameters.

## Function Overriding
Derived classes overriding parent class functions.
